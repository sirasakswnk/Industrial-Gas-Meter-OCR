  • ตารางประวัติแยกตามชุดมิเตอร์
  • เทียบค่าที่โมเดลอ่านกับค่าที่บันทึก
  • เรียกดูภาพต้นฉบับและออกรายงานซ้ำ

รับคำขอและตรวจสอบ
ข้อมูลนำเข้า

  • ตรวจชนิดไฟล์ที่อัปโหลด
  • สร้างรหัสประจำคำขอ
  • ควบคุมลำดับการทำงาน

เตรียมภาพ

preprocess_meter_image()
  • ปรับทิศทางตาม EXIF และแปลงเป็น RGB
  • ตรวจจับหน้าปัดด้วย YOLO-OBB
  • ปรับภาพให้ตรงด้วยการแปลงมุมมอง
  • ปรับความคมชัดด้วย OpenCV

ตรวจสอบชุดภาพ

check_request_meter_types()
  • อนุญาตภาพ EVC หลายภาพคู่กับ Turbine หนึ่งภาพ
  • ปฏิเสธคำขอที่มีภาพ analog เกินหนึ่งภาพ

ประกอบผลลัพธ์

build_ocr_result()
  • รับค่าดิบจากชั้นแบบจำลอง
  • กรองค่าที่ไม่ใช่ของมิเตอร์ analog ออก
  • เตรียมค่าเริ่มต้นของช่องทีละหลัก

คำนวณค่าที่บันทึก

reading_fields.py
  • ตัดทศนิยมของ TURBINE V. ตามที่ผู้ใช้เลือก
  • หาฟิลด์ที่ถูกแก้ด้วยมือ
  • คำนวณผลต่างจากการจดครั้งก่อน

Layer

YOLO-OBB

best_obb.pt
  • ตรวจจับตำแหน่งหน้าปัดและมุมทั้งสี่
  • จำแนกชนิดเป็น digital_screen หรือ analog_dial
  • ทำงานบนเครื่องผู้ใช้ผ่าน GPU

ocr_engines/ — OcrEngine (abstract)

เลือกแบบจำลองด้วยค่า OCR_ENGINE ใน .env

GeminiEngine

บริการภายนอก
  • ส่งภาพทั้งชุดในคำขอเดียว
  • บังคับรูปแบบผลลัพธ์ด้วย MeterReading

GlmEngine

Ollama บนเครื่อง
  • ส่งหนึ่งภาพต่อหนึ่งคำขอ
  • คำนวณค่าความเชื่อมั่นจาก logprobs

MeterReading

Pydantic Data Contract
  • นิยามฟิลด์ค่ามิเตอร์ทั้งหมด
  • ใช้บังคับรูปแบบผลลัพธ์
  • ตรวจสอบความถูกต้องก่อนส่งต่อ
